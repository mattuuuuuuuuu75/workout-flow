# 筋トレNOW スタジオ（自宅IROTEC ＆ 出張ホテル対応 × 厳密フォーム図解 × ショウコさん音声 × 5分瞑想）

スマホ横画面（マグネット固定）やタブレットで開き、**「▶ スタート」を1回押すだけで「部位別筋トレ → 膝保護HIIT → 日替わり股割りストレッチ → 仕上げ5分瞑想」まで全自動で流れる**専用Webアプリです。

## 主な特徴（v3）
1. **「建設NOWニュース」デザインシステム ＆ ショウコさん実アイコン**
   - 明るい部屋でもホテル客室でも見やすい白カード×濃紺×安全オレンジ（`#EA580C`）の工業メディア風UI。
   - 建設NOWニュース公式の**ショウコさんアイコン**と対話吹き出しを搭載。
2. **全29種・1枚ずつ機械的構造を厳密検証した専用フォーム図解イラスト**
   - グリップの向き（横バー順手／縦バーパラレル／ダブルD／ロープ）、プーリーの上下位置、ケーブル軌道、矢印の向き、効く筋肉のハイライトまで厳密に一致させた16:9単体図解イラストを搭載。
3. **サーバー不要・再生ラグゼロの「ショウコさん」音声同梱（全123ボイスMP3）**
   - Gemini TTS（`Leda`）で事前収録した全123種類のショウコさん音声MP3を同梱。PC電源OFFでもGitHub Pages上から即座に再生されます。
4. **毎日のラストに「仕上げの5分間瞑想」を自動組み込み**
   - 自律神経を整えるハープヒーリング瞑想（`sx9-adj0aLw`）とマインドフルネス瞑想（`bHR6HC7D7vA`）の2本を日替わりで自動ローテーション再生（ワンタップ切替対応）。
5. **自宅Wi-Fiでも出張先ホテルでも同じ固定URLでアクセス（GitHub Pages対応）**
   - 固定URL：`https://mattuuuuuuuuu75.github.io/workout-flow/`（ホテルモード直リンク：`?loc=hotel`）
   - 今後の内容更新は `publish-update.bat` を実行するだけで同じURLのまま即反映されます。
